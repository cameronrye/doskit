# DosKit

> A robust, cross-platform DOS emulator powered by js-dos WebAssembly technology

## Overview

DosKit is a modern web application that enables users to run classic DOS applications and demos directly in their browser. Built with React 19, TypeScript, and Vite, it leverages js-dos v8.3.20 for high-performance DOS emulation through WebAssembly.

It comes with a library of demoscene productions and music trackers, among them Second Reality, Crystal Dream 2, Impulse Tracker and Scream Tracker 3.

## Key Features

- **Interactive DOS Prompt**: The start page boots a fully functional DOS command prompt, with the application selector open over it
- **Cross-Platform**: Works on Windows, macOS, Linux, iOS, and Android
- **Progressive Web App**: Installable; after the first visit the app works offline, and each application does once it has been opened online
- **Deep Linking**: Load specific applications via URL parameters
- **WebAssembly Performance**: DOSBox compiled to WebAssembly, running in a worker thread
- **Full Keyboard & Audio Support**: Complete DOS experience including Sound Blaster emulation
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Type-Safe**: Full TypeScript support with comprehensive type definitions

## Technology Stack

- React 19 - Modern UI framework
- TypeScript 5 - Type-safe JavaScript
- Vite 8 - Next-generation frontend tooling, bundling with Rolldown
- js-dos 8.3.20 - WebAssembly DOS emulator (DosKit runs its DOSBox backend)
- Sharp - Image processing for the icons and social media previews

## Project Structure

- `/src/components/` - React components including DosPlayer
- `/src/config/` - Application registry, DOSBox and js-dos configuration files
- `/src/dos-apps/` - DOS application configurations
- `/src/hooks/` - Custom React hooks
- `/src/types/` - TypeScript type definitions
- `/src/utils/` - Utility functions
- `/public/` - Static assets, the service worker and the application archives (`/public/demos/`)
- `/scripts/` - Build scripts
- `/docs/` - Documentation

## Usage

Visit https://doskit.net/ to use the emulator directly in your browser. The application can be installed as a PWA for offline use.

Deep linking example: `https://doskit.net/?app=secondreality`
